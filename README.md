# 📊 Telco Customer Churn Analysis Dashboard (Excel)

## 📌 Project Overview

This project analyzes customer churn data using Microsoft Excel to identify patterns influencing customer retention and churn. The analysis includes data cleaning, transformation using Power Query, interactive dashboard creation, and business insights to support data-driven decision-making.

---

## 🎯 Business Objective

The goal of this project is to help businesses understand customer churn by answering questions such as:

* Which customers are most likely to churn?
* How do contract types influence customer retention?
* Which payment methods are associated with higher churn?
* How do monthly charges and tenure impact customer behavior?
* What actions can improve customer retention?

---

## 📂 Dataset

* **Dataset:** Telco Customer Churn Dataset
* **Source:** Kaggle (IBM Sample Dataset)
* **Records:** 7,043 customers
* **Features:** 21 customer attributes

## 🧹 Data Cleaning & Preparation

The dataset was cleaned and prepared using **Power Query** in Excel.

Data preparation steps included:

* Converted columns to appropriate data types.
* Handled missing values in the **TotalCharges** column.
* Removed inconsistencies in the dataset.
* Verified categorical values.
* Performed column profiling.
* Prepared the dataset for dashboard creation.

---

## 📈 Dashboard Features

The interactive Excel dashboard includes:

* KPI Cards

  * Total Customers
  * Churned Customers
  * Churn Rate
  * Average Monthly Charges

* Customer Demographics Analysis

* Contract Type Analysis

* Payment Method Analysis

* Internet Service Analysis

* Monthly Charges vs Churn

* Tenure Analysis

* Interactive Slicers for dynamic filtering

---



## 💡 Key Insights

Some of the insights obtained from the analysis include:

* Month-to-month contract customers have the highest churn rate.
* Customers with shorter tenure are more likely to churn.
* Electronic Check is associated with higher churn compared to other payment methods.
* Higher monthly charges tend to correlate with increased churn.
* Long-term contracts significantly improve customer retention.
